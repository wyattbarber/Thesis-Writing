\subsection{Failure of Perch Detection and Possible Improvements}

The overall perch detection rate is poor, with under 70\% of samples being detected 
correctly in the best scenario. 

Introducing the threshold based background separation did drastically improve performance against the white background. 
This is not surprising, as a plain white background with a single dark object 
is where binary image thresholding is best at separating foreground from background.
Interestingly the thresholding harmed the performance against the high-contrast patterned background. Why this is 
happening, and what is causing the remaining failures, is not obvious. The next subsections examine some represantative failures
to determine possible causes.

There is one notable difference between the point cloud in figure \ref{fig:ptcloud-ptrn-nothresh}, where the object was correctly detected, and in figure
\ref{fig:ptcloud-ptrn-thresh}, where artifacts in the foreground were detected as the perch instead: when the thresholding is disabled, more background points
are included in the point cloud and detected as possible lines. This appears to "distract" the detector from the line in the foreground. This does make sense based
on how the Hough transform algorithm used is implemented. It iteratively returns the line with the most votes, up to a maximum of 10 lines. With so many highly voted lines 
in the background, the smaller erroneous line in the foreground is low enough in votes that the 10 line limit is reached before it would be returned as a candidate. But when
the background is not filtered out, then that small line is closer to the top of the vote count because there are not a large number of background points above it in the list.

The reasoning for the small line being in the point cloud in the first place is hard to diagnose. One possibility is that it is the result of calibration error. 
Similar regions of high disparity error can be seen in the lower right corner of figures \ref{fig:disparity-nothresh}, \ref{fig:disparity-thresh}, 
\ref{fig:ptcloud-ptrn-nothresh}, and \ref{fig:disparity-ptrn-thresh}. Similar error across all 4 cases does support calibration errors, as the cameras and their calibration parameters
are constant across all test trials.
